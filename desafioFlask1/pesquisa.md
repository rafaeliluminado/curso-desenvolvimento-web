# Pesquisa: Flask, Python e Frameworks Web

## 1. O que é o Flask?
O Flask é um micro-framework para Python focado em simplicidade e flexibilidade. Ele fornece as ferramentas essenciais para subir um servidor web, tratar rotas e requisições sem impor estruturas engessadas ou dependências obrigatórias.

## 2. Python na Web e Template Engines
* **Python no Back-End:** Processa as regras do sistema, lida com dados e envia respostas dinâmicas ao cliente.
* **Template Engine (Jinja2):** Permite misturar HTML com variáveis e estruturas de repetição/condicionais em Python para gerar páginas dinâmicas.

## 3. Instalação e Execução (Quickstart)
1. Instalar o Flask: `pip install Flask`
2. Criar o arquivo `app.py` com o código básico.
3. Rodar no terminal: `flask run`
4. Acessar no navegador pelo endereço `http://127.0.0.1:5000`.

# Relatório de Laboratório - Aula 01

## Parte 1: Engenharia Reversa de Sintaxe

### Questão 1
* **Resposta:** Trecho C (XML)
* **Justificativa:** O XML foca na semântica e na estrutura dos dados (utilizando tags customizadas) para comunicação entre sistemas, sem se preocupar com a exibição visual na tela.

### Questão 2
* **Resposta:** Trecho B (Markdown)
* **Justificativa:** O Markdown é uma linguagem leve e limpa, ideal para documentação rápida em repositórios sem a necessidade de abrir e fechar tags complexas.

### Questão 3
* **Resposta:** Trecho A (HTML5)
* **Justificativa:** O HTML5 é a linguagem padrão da web usada para estruturar a interface e as páginas que o usuário final navega no computador ou celular.

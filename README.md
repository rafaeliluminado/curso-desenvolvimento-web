# Curso de Desenvolvimento Web - HTML, CSS e JS

Este repositório contém todo o meu progresso, exercícios e projetos desenvolvidos ao longo do curso de Desenvolvimento Web.

## 📁 Estrutura do Repositório

- **assets/**: Arquivos de mídia, imagens e recursos visuais.
- **docs/**: Documentações, manuais e guias de referência.
- **js/**: Scripts e arquivos de lógica em JavaScript.
- **pages/**: Páginas auxiliares dos projetos.
- **tabelas/**: Exercícios práticos focados na construção de tabelas HTML.
- **Aulas (aulaHTML01 ao 09)**: Práticas de sala de aula e conceitos fundamentais.
- **Projetos**:
  - `projeto-novashop`: Loja virtual com fluxo de produtos e carrinho.
  - `tech-blog`: Blog de tecnologia estilizado.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
